    สร้างอีเวนต์ตีแบดใหม่

    ตั้งค่าเชื่อมต่อ Firebase เรียลไทม์

    วิธีใช้งานให้เพื่อนซิงก์รายชื่อถึงกันแบบเรียลไทม์:
    1. สร้างโปรเจกต์ฟรีบน Firebase Console แล้วเปิดใช้งานเมนู Realtime Database
    2. คัดลอกลิงก์ฐานข้อมูล (ที่ลงท้ายด้วย .firebasedatabase.app หรือ .firebaseio.com) หรือก๊อปปี้โค้ด firebaseConfig มาวางด้านล่างเพื่อเชื่อมต่อทันที
    3. ก่อนนำไฟล์ขึ้น Git แนะนำให้นำค่า databaseURL ไปใส่ในตัวแปร DEFAULT_FIREBASE_CONFIG ในไฟล์ index.html เพื่อให้เพื่อนทุกคนเปิดเว็บแล้วเชื่อมต่ออัตโนมัติทันที
